Get started on Windows.

Download the setup, accept the terms and let it download the remaining components automatically. Internet and administrator access are required.

Windows 11 x64. Allow 12 GB of free space during setup. Local neural portrait processing needs supported NVIDIA CUDA hardware. Use a valid MYCAM activation key or purchase access inside the app.

Installer revision 1.0.0-r2 repairs camera startup error 0x80040111. Reinstall, then restart Windows. Windows 11 N users also need the Media Feature Pack if it is not installed.

This release is not publisher-signed, so Windows may show an unknown-publisher warning. Check the official release and its SHA-256 checksum before installing.
