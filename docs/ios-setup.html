Before you start

Prepare the phone

  • Back up the iPhone before changing its jailbreak state.
  • Charge the phone and keep a reliable Lightning cable connected.
  • Use a USB-A to Lightning cable when possible; USB-C can cause DFU problems.
  • MYCAM uses a rootless package, so choose the Rootless palera1n environment.

Semi-tethered behavior

  • The phone can restart into normal iOS without a computer.
  • After a reboot, run the jailbreak again to return to the jailbroken state.
  • Your installed jailbreak packages remain and return after rejailbreaking.
iPhone 8, 8 Plus and X on iOS 16: Palera1n requires passcode and SEP restrictions. If a passcode was previously configured, the official guide says the device must be erased before jailbreaking, with the passcode kept disabled while jailbroken. This also affects Touch ID, Face ID and Apple Pay.

Mac jailbreak setup

Use the official Palera1n installer in Terminal, verify the installation, then start a Rootless jailbreak.

1

Install Palera1n

Open Terminal and run the official installation script. Press Enter when prompted and accept adding Palera1n to PATH if asked.

/bin/sh -c "$(curl -fsSL https://static.palera.in/scripts/install.sh)"
2

Verify the installation

Confirm that Terminal can find Palera1n and display its installed version.

palera1n --version
3

Start Rootless mode

Connect the iPhone before running the command. Press Enter when Palera1n is ready and follow its on-screen recovery and DFU instructions.

palera1n -l
4

Install Sileo

When the iPhone boots, open the Palera1n Loader, select Sileo, and allow the bootstrap installation to finish. Sileo will then appear on the Home Screen.

Apple Silicon note: if Palera1n displays Checkmate! but stops progressing through a USB-C port, unplug and reconnect the cable as described by the official guide.

Supported iOS versions and devices

For this MYCAM setup, use iOS or iPadOS 15.0 or later on a Palera1n-compatible checkm8 device with an A8 through A11 chip. Newer iPhones such as iPhone XS, XR, 11 and later are not supported by Palera1n.

Install MYCAM from Sileo

1. Add the ElleKit repository

Open Sileo, go to Sources, choose Add Source, and enter the official ElleKit repository URL.

https://ellekit.space/
Add ElleKit source

2. Install ElleKit

Refresh Sources, search for ElleKit, tap Get, complete the queue, and respring if Sileo requests it.

3. Add the MYCAM repository

Return to Sources, choose Add Source, and enter the official MYCAM repository URL.

https://shareswhatyoucan.com/mycam/
Add MYCAM source

4. Install MYCAM iOS

Refresh Sources, open MYCAM iOS, tap Get, complete the queue, and respring when Sileo requests it.

Use jailbreak tools only on devices you own. Back up important data and follow the linked official documentation when troubleshooting.
